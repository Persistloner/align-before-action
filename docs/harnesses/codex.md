# Codex Adapter

This is the native packaging path for `align-before-action`.

## What stays the same

- The skill body in `skills/align-before-action/SKILL.md`
- The Codex metadata in `skills/align-before-action/agents/openai.yaml`
- The align-first, act-later contract

## What changes

- Codex uses `$align-before-action`
- Codex may auto-suggest the skill when unresolved information is high-impact

## Install

Copy the `skills/align-before-action` directory into your Codex skills location and reload Codex.
